# Эмулятор командной оболочки

## Общее описание

Консольный эмулятор UNIX-подобной командной оболочки,
реализованный на Python.

На первом этапе реализован минимальный прототип приложения
с интерактивным режимом работы. Реализовано формирование
приглашения на основе имени пользователя и имени компьютера,
разбор введённых команд с поддержкой аргументов в кавычках,
обработка ошибок и команды-заглушки `ls` и `cd`, а также
команда `exit`.

## Структура проекта

* `src/` — исходный код приложения;
* `tests/` — тесты приложения;
* `run.bat` — запуск приложения в Windows;
* `.gitignore` — список файлов и папок, исключённых из репозитория;
* `README.md` — описание проекта.

## Основные функции

`get_prompt()` — формирование приглашения командной оболочки
на основе имени текущего пользователя и имени компьютера.

`parse_input()` — разбор введённой пользователем команды
с помощью `shlex.split()`, включая корректную обработку
аргументов, заключённых в кавычки.

`main()` — основной цикл интерактивного взаимодействия
с пользователем.

`ls`, `cd` — команды-заглушки, выводящие имя команды
и переданные ей аргументы.

`exit` — завершение работы эмулятора.

Также реализована обработка неизвестных команд,
синтаксических ошибок при разборе строки и прерывания
работы программы с помощью `Ctrl+C`.

## Настройки

На первом этапе дополнительные параметры запуска
не используются.

Приглашение формируется автоматически на основе данных
операционной системы:

```text
username@hostname:~$
```

## Запуск

Windows:

```bash
run.bat
```

Также приложение можно запустить напрямую:
```bash
python src\main.py
```

## Пример
```text
username@hostname:~$ ls
Executing command 'ls' with args: []

username@hostname:~$ ls file.txt
Executing command 'ls' with args: ['file.txt']

username@hostname:~$ cd "test directory"
Executing command 'cd' with args: ['test directory']

username@hostname:~$ unknown
shell: command not found: unknown

username@hostname:~$ ls "test
shell: syntax error: No closing quotation

username@hostname:~$ exit
```
