# Эмулятор оболочки ОС (UNIX-like Shell Emulator)

Минималистичный эмулятор командной строки UNIX-подобной операционной системы, реализованный на Python. Проект разрабатывается в рамках лабораторной работы.

## Этап 1. REPL (Read-Eval-Print Loop)

Цель этапа — создание минимального консольного прототипа, поддерживающего интерактивный диалог с пользователем, разбор аргументов с кавычками и обработку команд-заглушек.

### Реализованная функциональность

1. **Консольный интерфейс (CLI):** Работа в бесконечном цикле обработки команд.
2. **Динамическое приглашение (Prompt):** Формируется на основе реальных данных операционной системы (`username@hostname:~$`).
3. **Корректный парсинг аргументов:** Поддержка аргументов с пробелами, обособленных двойными или одинарными кавычками.
4. **Обработка ошибок:** Вывод понятных сообщений при вводе неизвестных команд или синтаксических ошибках (незакрытые кавычки).
5. **Команды-заглушки:**
   - `ls` — выводит имя команды и список переданных аргументов.
   - `cd` — выводит имя команды и список переданных аргументов.
6. **Завершение работы:** Реализована команда `exit`, а также обработка сочетаний клавиш `Ctrl+C` (KeyboardInterrupt) и `Ctrl+D` (EOFError).
