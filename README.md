# Эмулятор командной оболочки

## Общее описание

Консольный эмулятор UNIX-подобной командной оболочки,
реализованный на Python.

На первом этапе реализован минимальный прототип приложения
с интерактивным режимом работы. Реализовано формирование
приглашения на основе имени пользователя и имени компьютера,
разбор введённых команд с поддержкой аргументов в кавычках,
обработка ошибок и команды-заглушки `ls` и `cd`, а также
команда `exit`.

На втором этапе добавлена возможность настройки приложения
с помощью параметров командной строки и конфигурационного
файла в формате TOML. Также реализован запуск стартового
скрипта с командами эмулятора перед переходом в
интерактивный режим.

## Структура проекта

* `src/` — исходный код приложения;
* `tests/` — тестовые файлы и сценарии проверки;
* `run.bat` — запуск приложения в Windows;
* `.gitignore` — список файлов и папок, исключённых из репозитория;
* `README.md` — описание проекта;
* `config.toml` — конфигурационный файл приложения.

## Основные функции

`get_prompt()` — формирование приглашения командной оболочки
на основе имени текущего пользователя и имени компьютера.

`parse_input()` — разбор введённой пользователем команды
с помощью `shlex.split()`, включая корректную обработку
аргументов, заключённых в кавычки.

`parse_arguments()` — обработка параметров командной строки:
пути к VFS, стартовому скрипту и конфигурационному файлу.

`load_config()` — чтение конфигурационного файла в формате
TOML и обработка ошибок его чтения.

`get_config_value()` — получение параметров из конфигурационного
файла и проверка их наличия.

`resolve_settings()` — формирование итоговых параметров
приложения с учётом приоритета параметров командной строки
над параметрами конфигурационного файла.

`print_settings()` — вывод итоговой конфигурации приложения
при запуске.

`execute_command()` — выполнение поддерживаемых команд
эмулятора и определение необходимости завершения программы.

`execute_line()` — разбор и выполнение одной команды.

`run_startup_script()` — чтение и выполнение команд из
стартового скрипта. При возникновении первой ошибки выполнение
скрипта прекращается. Команда `exit` также завершает выполнение
эмулятора.

`run_repl()` — интерактивный режим работы с пользователем.

`ls`, `cd` — команды-заглушки, выводящие имя команды
и переданные ей аргументы.

`exit` — завершение работы эмулятора.

Также реализована обработка неизвестных команд,
синтаксических ошибок при разборе строки, ошибок чтения
конфигурационного файла и ошибок выполнения стартового
скрипта.

## Настройки

На втором этапе приложение поддерживает три параметра
командной строки:

* `--vfs-path` — путь к физическому расположению VFS;
* `--startup-script` — путь к стартовому скрипту;
* `--config` — путь к конфигурационному файлу в формате TOML.

Параметр `--config` является обязательным.

Конфигурационный файл содержит параметры:

```toml
vfs_path = "vfs"
startup_script = "tests/startup.txt"
```

Если параметр `--vfs-path` или `--startup-script` указан
в командной строке, используется значение из командной строки.
Если параметр не указан, его значение берётся из
конфигурационного файла.

Таким образом, параметры командной строки имеют приоритет
над параметрами из конфигурационного файла.

Путь к VFS на данном этапе только считывается и выводится
в отладочной информации. Работа с самой виртуальной файловой
системой будет реализована на следующем этапе.

При запуске приложение выводит итоговую конфигурацию:

```text
Emulator configuration:
VFS path: vfs
Startup script: tests/startup.txt
Config file: config.toml
```

## Стартовый скрипт

Перед переходом в интерактивный режим приложение выполняет
команды из указанного стартового скрипта.

Команды отображаются на экране вместе с приглашением,
имитируя ввод пользователя.

Например, файл `startup.txt`:

```text
ls
cd test
```

приводит к следующему выводу:

```text
username@hostname:~$ ls
Executing command 'ls' with args: []

username@hostname:~$ cd test
Executing command 'cd' with args: ['test']
```

После завершения стартового скрипта приложение переходит
в интерактивный режим.

При возникновении ошибки выполнение стартового скрипта
прекращается на первой ошибочной команде.

Например:

```text
ls
unknown
cd test
```

После выполнения `unknown` команда `cd test` выполняться
не будет.

Если стартовый скрипт содержит команду `exit`, выполнение
эмулятора полностью завершается и интерактивный режим
не запускается.

## Запуск

Windows:

```bat
run.bat
```

Для запуска с конфигурационным файлом:

```bat
run.bat --config config.toml
```

Также приложение можно запустить напрямую:

```bat
python src\main.py --config config.toml
```

Параметры командной строки можно задавать непосредственно
при запуске:

```bat
python src\main.py --config config.toml --vfs-path custom_vfs --startup-script tests\startup.txt
```

При этом значения `--vfs-path` и `--startup-script` из
командной строки имеют приоритет над значениями из
`config.toml`.

## Обработка ошибок

Если конфигурационный файл не найден или содержит
некорректный TOML, приложение сообщает об ошибке:

```text
shell: config error: ...
```

Если стартовый скрипт не найден или не может быть открыт:

```text
shell: startup script error: ...
```

Если во время выполнения стартового скрипта встречается
неизвестная команда:

```text
shell: command not found: unknown
shell: startup script execution failed
```

После первой ошибки выполнение стартового скрипта
прекращается.

Если обязательный параметр `--config` не указан,
ошибка обрабатывается стандартным механизмом `argparse`.

## Пример

Запуск:

```text
python src\main.py --config config.toml
```

Вывод конфигурации:

```text
Emulator configuration:
VFS path: vfs
Startup script: tests/startup.txt
Config file: config.toml
```

Выполнение стартового скрипта:

```text
username@hostname:~$ ls
Executing command 'ls' with args: []

username@hostname:~$ cd "test directory"
Executing command 'cd' with args: ['test directory']
```

После выполнения стартового скрипта запускается
интерактивный режим:

```text
username@hostname:~$ ls file.txt
Executing command 'ls' with args: ['file.txt']

username@hostname:~$ unknown
shell: command not found: unknown

username@hostname:~$ exit
```

Проект использует только стандартные библиотеки Python.
